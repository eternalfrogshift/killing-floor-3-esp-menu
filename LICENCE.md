## 🧩 About

**Killing Floor 3 Companion** is a curated list of Killing Floor 3 open-source tools:

- **Overlays** — on-screen helpers, layout notes, threat viewer, wave tracker
- **Quality-of-Life Helpers** — loadout catalog, perk manager, overlay notes
- **Research Notes** — wave layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Wave Helpers
- Wave Tracker — practice from any wave checkpoint
- Threat Viewer — visualize specimen outlines for study
- Replay Notes — record and review wave runs
- Playback Speed — adjust demo playback for study (0.1x to 5x)

### 🎨 Loadout & Cosmetics
- Loadout Catalog — browse perks, weapons, skins, camos
- Custom Skin Notes — organize player cosmetics
- Team Highlight — improved teammate visibility

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any map
- Zed Time Control — manually review slow-motion windows
- Trader Timer Notes — chain complex rotations in the editor
